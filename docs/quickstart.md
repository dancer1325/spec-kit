# Quick Start Guide

* ⭐️types of paths⭐️
  * 💡short💡
    * step process
      * [install Specify CLI](installation.md)
      * `/speckit.specify`
      * `/speckit.plan`
      * create a PR -- to -- review ALL
      * `/speckit.tasks`
      * `/speckit.implement`
      * `/speckit.converge`
        * if it finds gaps -> 
          * `/speckit.implement`
          * `/speckit.converge`
      * create a PR -- to -- review ALL
    * use case
      * small features
  * 💡full💡 
    * step process
      * [install Specify CLI](installation.md)
      * `/speckit.constitution`
      * `/speckit.specify`
      * `/speckit.clarify`
      * `/speckit.plan`
      * create a PR -- to -- review ALL
        * OPTIONAL
      * `/speckit.checklist`
      * `/speckit.tasks`
      * `/speckit.analyze`
      * create a PR -- to -- review ALL
        * recommended
      * `/speckit.implement`
      * `/speckit.converge`
        * if it finds gaps -> 
          * `/speckit.implement`
          * `/speckit.converge`
      * create a PR -- to -- review ALL
    * use case
      * production features
